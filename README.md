# AI Architect — мастер-класс 24 сентября

Статический лендинг для GitHub Pages. Сборка не требует сторонних зависимостей.

## Локальная проверка

```bash
npm run build
npm run serve
```

Затем открыть `http://localhost:4173`.

## Регистрация

Форма не передаёт данные на сервер. Она формирует черновик заявки и открывает диалог с `@yan_lukashin` по официальной Telegram deep link. UTM, `yclid` и `gclid` добавляются в текст заявки.

Перед холодным трафиком рекомендуется подключить Google Form или CRM с полной политикой обработки данных.

## Публикация

Workflow `.github/workflows/pages.yml` собирает `dist/` и публикует GitHub Pages при каждом push в `main`.
