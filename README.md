# AI Architect — мастер-класс 24 сентября

Статический лендинг для GitHub Pages. Сборка не требует сторонних зависимостей.

Опубликованная версия: https://yanlukashin.github.io/ai-architect-masterclass/

## Локальная проверка

```bash
npm run build
npm run serve
```

Затем проверить `http://localhost:4173` в изолированном headless-браузере.

## Архивный маршрут

Мастер-класс прошёл 24 сентября 2026 года. Основной переход ведёт на [запись и Canvas](https://hype-and-hope.ru/masterclass-2026-09-24); отдельная ссылка на обсуждение задачи ведёт на `/anketa?interest=diagnostic&source=/masterclass` основного сайта. Активной регистрации и отправки в Google Form на этой странице больше нет. Скрипт переносит на основной сайт только безопасные значения известных параметров `utm_*`, `yclid`, `gclid` из текущего URL; контактные данные в URL не добавляются.

## Яндекс Метрика

Счётчик: `112342018`. Установлен код, переданный Яном: Вебвизор, карта кликов, отслеживание ссылок и точный показатель отказов. Текстовые поля анкеты помечены `ym-disable-keys`, в параметры целей ответы и контакты не передаются.

Исторические цели счётчика относились к прежней форме и больше не вызываются на архивной странице:

| Название | Идентификатор | Когда отправляется |
|---|---|---|
| Начало заполнения анкеты | `form_start` | Первое изменение поля или отправка валидной автозаполненной анкеты; один раз за открытие страницы |
| Анкета отправлена | `registration_sent` | Показ подтверждения после завершения запроса к Google Form без сетевой ошибки |
| Переход в канал мастер-класса | `telegram_click` | Клик по кнопке канала в подтверждении регистрации |

Старые данные и определения целей следует трактовать как историю прежнего лендинга. Код Метрики для просмотра страницы остаётся; переходы на основной сайт отслеживаются обычным отслеживанием ссылок.

## Публикация

Workflow `.github/workflows/pages.yml` собирает `dist/` и публикует GitHub Pages при каждом push в `main`.
