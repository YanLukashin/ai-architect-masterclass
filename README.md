# AI Architect — мастер-класс 24 сентября

Статический лендинг для GitHub Pages. Сборка не требует сторонних зависимостей.

Опубликованная версия: https://yanlukashin.github.io/ai-architect-masterclass/

## Локальная проверка

```bash
npm run build
npm run serve
```

Затем открыть `http://localhost:4173`.

## Регистрация

Форма на лендинге отправляет ответы в [Google Form](https://docs.google.com/forms/d/e/1FAIpQLSev1ox1t_KXnsRxpOIrK9QdGg1a_bdmedF_h-hGGgwof39abw/viewform). Телефон обязателен; Telegram можно оставить как дополнительный способ связи. На лендинге телефон передаётся в существующее поле Google Form `entry.172638223`, которое пока называется Email; внешний вопрос этой задачей не меняется. UTM, `yclid` и `gclid` сохраняются в поле источника заявки.

После успешной отправки появляется кнопка вступления в [Telegram-канал мастер-класса](https://t.me/+xR-I608Nv7EwODQy). Напоминания и ссылка Zoom публикуются в канале; ссылка Zoom появится ближе к эфиру. Автоматическая отправка сообщений не настроена.

7 сентября из Google Form удалён повторявшийся вопрос «Можно предложить ваш пример для разбора?». Отправка заявки после удаления проверена; совместимая передача полей на лендинге сохранена.

## Яндекс Метрика

Счётчик: `112342018`. Установлен код, переданный Яном: Вебвизор, карта кликов, отслеживание ссылок и точный показатель отказов. Текстовые поля анкеты помечены `ym-disable-keys`, в параметры целей ответы и контакты не передаются.

В кабинете счётчика нужно создать три цели типа «Целевое событие», условие «совпадает»:

| Название | Идентификатор | Когда отправляется |
|---|---|---|
| Начало заполнения анкеты | `form_start` | Первое изменение поля или отправка валидной автозаполненной анкеты; один раз за открытие страницы |
| Анкета отправлена | `registration_sent` | Показ подтверждения после завершения запроса к Google Form без сетевой ошибки |
| Переход в канал мастер-класса | `telegram_click` | Клик по кнопке канала в подтверждении регистрации |

Код отправляет события через `reachGoal`. Создание целей в кабинете и появление достижений в отчёте требуют отдельной проверки. Метрика не должна блокировать регистрацию, если её загрузку отключил браузер.

`registration_sent` — событие интерфейса: при `fetch` в режиме `no-cors` сайт не читает ответ Google и не подтверждает запись в форме. Число реальных регистраций сверяем с ответами Google Form. `telegram_click` фиксирует переход, а не вступление в канал.

## Публикация

Workflow `.github/workflows/pages.yml` собирает `dist/` и публикует GitHub Pages при каждом push в `main`.
